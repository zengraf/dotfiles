# Custom skills

When I type one of these triggers, invoke the matching skill via the Skill tool before doing anything else:

- **`/implement`** — fetch a Linear ticket, create a branch, assess scope, and produce a plan in native Plan Mode.
- **`/deep-review`** — review a PR branch with GitHub + Linear context; output critical issues and nitpicks.
- **`/ctx`** — load, create, or switch the active task context (dense persistent memory; a SessionStart hook prompts for one and gates tools until you pick at the start of each chat).
